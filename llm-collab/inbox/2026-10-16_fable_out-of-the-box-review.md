---

**Most surprising insight.** The most valuable thing in the repository is the referee, not the protocol: two independent implementations plus a committed fuzz digest that already catch each other's mistakes in exactly the arithmetic the tools people run keep getting wrong, path and command-pattern matching and delegated budget conservation.

**1. A permission-pattern oracle ("does your matcher agree?").** Pain: the CVEs above and the open Claude Code thread; vendors' own docs say their rules are not a security boundary. No cross-tool corpus was found; the precedent for the form is the JSON Schema Test Suite. Smallest version: a JSON file of (rule, candidate, expected) built from the existing generator plus reproductions of the CVEs, one adapter per open-source matcher (Gemini CLI, OpenClaw, cc-safety-net, sembl, chock, Vectimus), findings filed as minimal reproductions. Failure modes: per-tool semantics differ, so only escalations count; vendors may decline; Claude Code is closed source. Test under ten hours: run it against Gemini CLI and OpenClaw allowlists; success is one maintainer merging a vector or fixing a case within three weeks.

**2. Budget arithmetic for sub-agent trees.** Pain: the CrewAI thread, Claude Code #72861 and #79735, A2A #2121. Competition: the Agent SDK's caps, shekel's nested budgets, LiteLLM team budgets; the in-process gap is closing, the cross-process, cross-owner gap is open. Smallest version: budget-vectors.json plus a 150-line checker in both languages, offered to #2121 and to shekel as a differential test. Test: shekel adopts or fixes a case, or #2121 references the file.

**3. The leash that tightens when the human goes quiet.** Pain, partly verified: always-on personal agents run unattended; approvals are not an auth boundary; a popular skill does the opposite (acts on when the owner disappears). Nobody found gating authority on the owner's presence. Smallest version: lap-leash, a credential broker usable as an OpenClaw exec secret provider that releases messaging and payment credentials only while a signed owner check-in is fresh; read scopes continue; optional successor handoff. Failure modes: owners want agents to work while away (scope-tiered weekly check-ins), stolen keys keep heartbeats going, OpenClaw could add "pause when inactive". Test: ask ten OpenClaw users whether payments and messaging should pause after seven silent days; success is three yeses and one install that reports a tightened-leash event in two weeks.

**Ranked lower** (pain / growth / reuse / copy-hard / cheapness): lap-git hooks 4/4/4/1/3 (crowded); agent DCO trailer checks 4/4/2/1/5; giving LIP-3 vectors to UCAN, Biscuit, AAE 2/3/5/2/5 (fold into 1 and 2); AP2 vectors 2/5/4/2/3; browser verifier 2/3/5/1/5; a paper on differential fuzzing 2/3/5/2/4; CTF 2/3/5/1/4; legal schedule of authority 2/4/3/1/5; MCP proxy 3/4/4/1/3; idempotency pattern 2/3/4/1/4; Home Assistant caps proxy 2/3/3/2/2; orphaned-automation finder 3/4/2/1/3; incident dataset 3/3/2/1/4; in-toto mapping 2/3/3/2/3; insurance format 2/4/3/2/1; consumer allowances 3/5/2/1/1; hosted liveness registry 1/3/3/2/1; retire the protocol, keep a scope library 2/3/5/1/5.

**Opinion on future potential.** Idea 3 has the longest runway: every guard, gateway and SDK answers "what may this agent do"; none answers "what happens when its human stops showing up". Ideas 1 and 2 earn the credibility to be heard; idea 3 is the one nobody else will build.
